# MQLC

## Introduction

The MQLC model is referenced from the repository available at:
https://github.com/angmavrogiannis/B-GAP-Behavior-Guided-Action-Prediction-and-Navigation-for-Autonomous-Driving.

Built upon the B-GAP model, MQLC is designed for multi-agent cooperative lane-changing decision-making through optimized observation mechanisms, improved neural network architectures, and cooperative decision strategies.

## Paper

**Title:** Mix Q-Learning for Lane Changing: A Collaborative Decision-Making Method in Multi-Agent Deep Reinforcement Learning
